# State of i18n in open-source apps (2026)

A reproducible benchmark of user-visible translation bugs (dropped, renamed or malformed placeholders) in company-backed open-source apps, built with [i18n-audit](https://github.com/theluckystrike/i18n-audit).

Report: https://theluckystrike.github.io/oss-i18n-report/ (GitHub Pages, served from `docs/`).

The goal is to help maintainers. Every finding lists the file, line, key, source string and translation, so it can be fixed quickly, and the report shows how to keep these bugs out with a CI check.

## Outputs

| File | What it is |
| --- | --- |
| `data/pr-targets.csv` | Repos without a translation management system (TMS), where fixes can go straight to the locale files, ranked by `findings x log10(stars + 10) x log2(2 + outside commits in 180 days)`, halved when locale files are regenerated by a script |
| `data/summary.csv` | One row per audited repo: stars, owner type, last push, TMS, locales, strings checked, findings by kind, worst locales |
| `data/<owner>__<repo>.json` | Everything for one repo, including every finding (file, line, key, locale, kind, source, translation), locale groups, TMS evidence and contribution activity |
| `data/skipped.csv` | Targets that were not audited, with the reason |
| `docs/` | The static report site, generated by `build_site.py` |

## Reproduce

Requirements: Python 3.10+ with PyYAML, git, Node 18+ (only for locale files written as TS/JS modules).

```sh
(cd tools && npm ci)          # esbuild, used to read TS/JS locale modules
python3 bench.py              # clones into .work/, writes data/
python3 build_site.py         # writes docs/
```

`python3 bench.py --only owner/repo` reruns a single target. Targets and per-repo overrides live in `targets.json`.

## Check your own repo in CI

```sh
python3 bench.py --check path/to/checkout   # exit code 1 if any finding
```

This uses the same locale discovery and classifier as the benchmark. See the "How to fix this in CI" section of the report for a workflow example.

## Method in short

1. Shallow, blob-less clone of the default branch with 180 days of history; sparse checkout of locale files and docs only.
2. Locale groups: files whose paths differ only by a locale code, with an English source and at least two translations.
3. Each translated string is compared with its English source by the pinned i18n-audit classifier (`tools/i18n_audit_seed.py`, see `tools/VENDORED.md`). The placeholder syntax (i18next, ICU, vue-i18n, Rails, printf, Python format) is detected per group.
4. Not counted: tag differences and plural forms that omit or add the count (reported as informational), nested `$t()` inlined by the translator, fuzzy PO entries, Crowdin in-context pseudo-translations.
5. TMS detection from config files, docs and workflow mentions, and bot authors of recent locale commits.
6. Stars and owner type come from repos.ecosyste.ms (fallback ungh.cc) because api.github.com was not reachable from the build environment. "Outside" activity is estimated from git history: a non-bot author active on at most 3 days in the 180-day window.

Limits: counts are an upper bound (some keys may be unused by the code); line numbers are best effort; the outside-contributor measure is a heuristic, not a count of merged PRs by non-members.
